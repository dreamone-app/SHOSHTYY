# رسالة لشوشو 💬

الموقع ده شكله وتجربته زي **محادثة واتساب حقيقية** جوه فريم موبايل، مش صفحة عادية بتتقلب فيها.

## الفكرة

- فريم موبايل حقيقي بشكل هاتف (notch + status bar + هيدر شات باسم "شهد")
- الرسايل بتظهر واحدة واحدة براحة زي محادثة حقيقية، مع مؤشر "بيكتب..." بينهم
- في اختيارات تفاعلية (Quick replies) بترد بيها "شهد" على الرسايل
- **تحدي القلوب**: لازم تمسك 10 قلوب 💜 وتتجنب القلوب المكسورة 💔 في وقت محدود، والسرعة بتزيد كل شوية عشان تحدي حقيقي وممتع
- **رسالة صورة**: ترفع صورة حقيقية بتتحط كأنها اتبعتت في الشات
- **رسالة صوتية** بشكل حقيقي (Waveform) بتشغل أغنية "على بالي" لرامي صبري
- **لغز عيد الميلاد**: معادلتين حسابيتين بسيطتين، لما تتحل صح بتكشف كارت فيه عداد تنازلي حي لـ 19 مايو
- **حكاية السماح**: اختيار "لسه شوية 😏" بيرجع يدلعها كذا مرة، وفي الآخر الاختيارين بيبقوا "خلاص سامحتك 😂❤"
- بعد السماح بتظهر **شهادة سماح رسمية** كأنها ملف مرفق في الشات، وتقدر تنزلها صورة PNG

## الرفع على GitHub Pages

مهم جدًا: ارفعي ملف `index.html` نفسه في **جذر الريبو (root)** — مش داخل فولدر، ومش كملف مضغوط (zip).

### الطريقة السريعة (من المتصفح، من غير تيرمينال)

1. اعملي ريبو جديد على GitHub (Public).
2. من صفحة الريبو: **Add file → Upload files**.
3. اسحبي ملف `index.html` (و`README.md` لو حابة) عليها مباشرة.
4. اعملي Commit.
5. من **Settings → Pages**: اختاري Source = branch `main` وفولدر `/ (root)`، واحفظي.
6. استني دقيقة، وهيديكي لينك زي:
   `https://USERNAME.github.io/REPO-NAME/`

### الطريقة بالتيرمينال

```bash
git init
git add .
git commit -m "نسخة الشات التفاعلية"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```
